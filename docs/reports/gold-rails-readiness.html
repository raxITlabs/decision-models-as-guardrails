Frozen configuration status

  • Declared now in benchmark/subsets/first-benchmark/implementations.json: seven systems, with Bedrock as the composite of its InvokeGuardrailChecks and ApplyGuardrail paths and the regex baseline for word filters. Also declared: the candidate question sets per suite, no supporting rules, the declared load, and transient-only retries.
  • Fixed by the tuning pass: one question set per system and suite (content tries two), and the thresholds, fitted on tuning rows only.
  • Then frozen: the freeze manifest is written, committed and pushed before the first test call. The runner refuses test calls without it, and final scoring loads its thresholds rather than refitting.

Declared exclusions

  • Indirect prompt attacks. Every set is separable by trivial baselines (n-gram AUROC 0.96 to 0.99). Diagnostic only.
  • Grounding query relevance. Deferred; no labelled source.
  • Masking. Scored separately, off the detection release's critical path.
  • Automated Reasoning. Excluded: formal verification is not detection.
  • Also out: managed profanity lists, images, non-English text, streaming and deployment controls.
  • Pending: bias B2 counterfactual pairs (after review) and denied topics (after review).
